## MetaVault AI

MetaVault AI is an LLM-assisted metadata engineering platform that automates the transformation of ERP schemas into Data Vault 2.0 models (Hubs, Links, Satellites).

Built using Python and Streamlit, the platform integrates AI-driven schema interpretation with rule-based validation and human-in-the-loop approval to ensure reliable and production-ready metadata.

### Key Features
- Automated Data Vault modeling (Hub-Link-Satellite)
- LLM-based business key and relationship detection
- Schema standardization and classification
- Validation engine for metadata quality
- Human-in-the-loop editing and approval workflow
- Versioned metadata storage (SQLite / Delta-ready)
- Modular architecture for Fabric / PySpark integration

### Workflow
ERP Schema → LLM Processing → Metadata Generation → Validation → Approval → Storage

### Tech Stack
- Python
- Streamlit
- OpenAI / Azure OpenAI
- SQLite / Delta Lake
- PySpark (extensible)

### Use Cases
- Data Vault modeling automation
- Metadata engineering acceleration
- Data governance and lineage preparation
- ERP-to-analytics pipeline design
